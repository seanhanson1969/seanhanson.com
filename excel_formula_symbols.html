Excel Formula Bar Symbols

Eight characters that change how Excel reads what you type. Click any card to see usage examples and tips. Filter by category using the buttons below.

Symbol 1
Period / Dot
Cell Reference
Used inside a range reference to separate the start cell from the end cell when using certain structured range notations. More commonly, the period is the decimal separator in numbers.
Primary Use — Decimal Separator
=A1*3.14
Multiplies A1 by pi (3.14)
Range Notation (R1C1 / structured)
=SUM(R1C1:R5C1)
In R1C1 notation, dot variants appear in some locale-specific range formats
In U.S. locale Excel, the dot is the decimal point in every numeric literal. It does not separate range addresses in standard A1 notation — that job belongs to the colon (:).

'
Symbol 2
Apostrophe
Text & Format
Forces Excel to treat a cell entry as text, not a number or formula. Type it first and Excel stores the value as a text string — even if it looks like a number.
Force Text Entry
'001234
Stored as text "001234" — leading zeros preserved
'=SUM(A1:A5)
Displayed literally as =SUM(A1:A5), not calculated
Sheet Name in References
='Sheet Name With Spaces'!A1
Apostrophes wrap sheet names that contain spaces or special characters
The leading apostrophe is invisible in the cell display but visible in the formula bar. It shows as a small green triangle warning in the corner of the cell.

SPACE
Symbol 3
Space (Intersect)
Operator
A single space between two range references is the intersection operator. It returns the cell(s) that two ranges share. It's the quietest operator in Excel — easy to miss, easy to mistype.
Intersection Operator
=B1:B10 A5:D5
Returns the value at B5 — the cell where those two ranges cross
=SUM(A1:A10 A3:A7)
Sums only A3:A7 — the overlapping portion
If the two ranges don't intersect, Excel returns a #NULL! error. This is one of the rare cases where a "typo" (forgetting a comma between ranges) actually does something — just not what you intended.

*
Symbol 4
Asterisk
Wildcard
Two jobs: wildcard for any number of characters in text-matching functions, and the multiplication operator in math formulas.
Multiplication Operator
=A1*B1
Multiplies values in A1 and B1
Wildcard — Any Number of Characters
=COUNTIF(A:A,"Blattner*")
Counts cells starting with "Blattner" (anything after)
=SUMIF(A:A,"*solar*",B:B)
Sums column B where column A contains "solar" anywhere in the text
Works in COUNTIF, SUMIF, VLOOKUP, MATCH, and similar functions. Does NOT work as a wildcard inside SUM or IF on its own — only in functions that explicitly support wildcards.

?
Symbol 5
Question Mark
Wildcard
Wildcard for exactly one character. Use it when you know the length of the text but not what a specific character is.
Single-Character Wildcard
=COUNTIF(A:A,"S?N")
Matches "SUN", "SAN", "SON", "SIN" — exactly 3 characters, S at start, N at end
=VLOOKUP("J?n",A:B,2,0)
Matches "Jan", "Jun", "Jon", etc.
Combining with Asterisk
=COUNTIF(A:A,"B????ner*")
Matches "Blattner", "Blattner Company", etc. — 4 unknown chars after B, then "ner"
The ? counts as exactly one position. Stack them to match a fixed-length unknown sequence. Combine with * when the tail is variable.

~
Symbol 6
Tilde
Wildcard
Escape character for wildcards. Put a tilde before * or ? to search for the literal character instead of treating it as a wildcard. Think of it as "I mean this literally."
Escape a Wildcard
=COUNTIF(A:A,"Price~*")
Counts cells containing the literal text "Price*" — not "Price" followed by anything
=MATCH("5~?",A:A,0)
Looks for the literal string "5?" in column A
Escape the Tilde Itself
=COUNTIF(A:A,"~~")
Counts cells containing a literal tilde character
Without the tilde escape, you cannot search for actual asterisks or question marks using wildcard-based functions. This trips up a lot of people dealing with part numbers or coded strings.

$
Symbol 7
Dollar Sign
Cell Reference
Locks a row, column, or both when copying formulas. Without it, references shift as you copy. With it, they stay put. The anchor that keeps your formula from drifting.
Absolute Column and Row
=$A$1
Always refers to A1 no matter where the formula is copied
Mixed References
=$A1
Column A locked, row shifts as formula is copied down
=A$1
Row 1 locked, column shifts as formula is copied right
Shortcut
Press F4 while the cursor is on a cell reference in the formula bar to cycle through all four reference types: A1 → $A$1 → A$1 → $A1 → back to A1.

&
Symbol 8
Ampersand
Text & Format
Text concatenation operator. Joins two or more strings or cell values into one. The "glue" of Excel formulas.
Join Text and Cell Values
=A1&" "&B1
Combines first name (A1), a space, and last name (B1) into one string
="Project: "&C3
Returns "Project: " followed by whatever is in C3
With Other Functions
=TEXT(A1,"MM/DD/YYYY")&" Report"
Formats a date and appends " Report" to it
=VLOOKUP(D1&E1,A:C,3,0)
Concatenates D1 and E1 to build a lookup key on the fly
The ampersand is functionally identical to CONCAT() or CONCATENATE(), but faster to type. Use TEXT() around numbers or dates before concatenating if you want specific formatting preserved.
